# Sydney trip planner

네이버·구글 블로그를 조사해 만든 시드니 여행 일정을 웹사이트로 옮긴 프로젝트입니다. 날짜는 들어 있지 않고, **비행기 도착·출발 일시를 넣으면 날짜와 요일이 맞춰집니다.**

## 기능

- **비행기 일정 입력:** 도착일·출국일 시간표가 비행기 시각에 맞춰 다시 계산됩니다.
  - 도착이 늦으면 저녁 일정을 줄이고, 출발이 이르면 출국일 오전 일정을 줄입니다.
- **일차별 일정 배치:** 도착일, 블루마운틴 투어, 시내 명소, 본다이, 포트스테판 투어, 출국일, 자유 일정을 원하는 날에 넣을 수 있습니다.
  - 요일이 안 맞는 장소(월·화 휴무인 패디스 마켓, 토·일만 여는 더 록스 마켓, 일요일만 여는 본다이 마켓, 평일만 여는 식당)는 ⚠로 알려줍니다.
- **일정과 지도:** 일차별 시간표와 동선 지도, 비 오는 날 대체 일정을 봅니다.
  - 시드니 예보에서 강수 확률이 60% 이상이면 비 오는 날 일정이 먼저 열립니다.
- **식당 추천:** 끼니마다 3곳을 추천하고, 이름·메뉴 검색과 일차 필터, 구글 지도 링크를 제공합니다.
- **편의 기능:** 시드니 현재 시각과 "지금 할 일", D-day, AUD→KRW 환율 계산, 다크 모드
- **여행 코드로 공유(Supabase):** 동행자와 아래 데이터를 함께 씁니다.
  - 비행기 일정
  - 방문 체크
  - 일차별 메모
  - 준비물 체크리스트
  - 경비 기록과 1/N 정산

## 시작하기

```bash
npm install
cp .env.example .env.local   # Supabase URL과 publishable key
npm run dev
```

Supabase 준비:

1. SQL Editor에서 `supabase/schema.sql`을 실행합니다.
2. `supabase/seed.example.sql`의 코드를 바꿔 여행을 하나 만듭니다.

Supabase 없이도 일정·지도·식당 화면은 동작합니다. 비행기 일정은 브라우저에 저장됩니다.

## 구조

- `src/data.js`: 일정 템플릿, 식당, 교통, 출처, 장소별 영업 요일
- `src/plan.js`: 비행기 일정과 템플릿 배치로 날짜별 일정을 만듭니다. 도착·출국일 시간 계산과 요일 경고도 여기서 합니다.
- `src/useTrip.js`, `src/useSettings.js`: Supabase RPC 호출과 설정 저장
- `src/components/`: 화면별 컴포넌트

DB 테이블은 API에서 직접 열 수 없습니다. `trip_load` 같은 `security definer` 함수가 여행 코드(bcrypt 해시)를 확인한 뒤에만 읽고 씁니다.

## 배포

Vercel(Vite)로 배포합니다. 환경변수 `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY`(publishable key)가 필요합니다.

## 주의

- 지도는 AI(Google Flow)로 그린 일러스트라 위치·거리는 대략적입니다.
- 가격·영업시간은 출처 글 작성 시점 기준입니다. 방문 전에 확인하세요.
